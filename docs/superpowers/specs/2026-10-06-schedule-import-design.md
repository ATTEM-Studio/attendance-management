# 근무표 자동 가져오기 설계

## 목적

관리자가 기존 Excel 근무표를 그대로 활용하면서 근태관리 앱의 월간 근무 일정으로 안전하게 가져올 수 있게 합니다.

현재 지원 형식은 **Excel `.xlsx` 전용**입니다. 이미지·사진·캡처·PDF 분석 기능은 범위에서 제외합니다.

## 사용자 흐름

1. 관리자 `근무 > 근무표 > 근무표 가져오기`를 엽니다.
2. `.xlsx` 파일을 선택합니다.
3. 브라우저가 workbook 안에서 근무표 후보 시트와 영역을 자동 탐지합니다.
4. 대상 월과 `변경 적용 시작일`을 확인합니다.
5. 직원명을 활성 직원과 자동 매칭하고, 애매한 이름만 관리자가 직접 연결합니다.
6. 서버가 현재 `schedules`, `extra_schedules`, `attendance`를 다시 읽고 diff를 계산합니다.
7. `신규 / 변경 / 삭제 / 보호 / 확인 필요 / 변경 없음`을 미리 확인합니다.
8. 적용 시 서버가 상태를 한 번 더 확인한 뒤 PostgreSQL RPC로 원자적으로 반영합니다.

## 핵심 안전 규칙

- 적용 시작일 이전 일정은 변경하지 않습니다.
- 실제 `clock_in` 또는 `clock_out`이 존재하는 직원/날짜는 자동 수정·삭제하지 않습니다.
- 부분 근무표로 판단된 파일은 보이지 않는 기존 일정을 삭제 근거로 사용하지 않습니다.
- 같은 직원의 같은 날 다중 근무는 시간순으로 기본 근무 + 추가 근무로 분리합니다.
- 겹치는 근무시간은 적용하지 않습니다.
- 미리보기와 적용 파일의 SHA-256 fingerprint가 다르면 적용하지 않습니다.
- 직원 매칭이 확정되지 않은 행이 남아 있으면 적용하지 않습니다.
- 원본 Excel 파일은 브라우저에서 처리하며 서버에 장기 저장하지 않습니다.

## 구성

- `schedule-import-core.js`
  - Excel 후보 영역 탐지
  - 주간 패턴 해석
  - 시간 정규화
  - 직원명 매칭
  - SHA-256 fingerprint 생성
- `schedule-import.js`
  - 4단계 관리자 UI
  - 별칭 재사용
  - 미리보기/적용 요청
- `supabase/functions/attendance-schedule-import/`
  - 관리자 세션 검증
  - 서버 diff 재검증
  - 원자적 적용
  - 별칭 저장/조회
- `supabase/migrations/20261006_schedule_import.sql`
  - import run/alias 저장소
  - 원자적 적용 RPC

## 비지원 범위

- PNG/JPG/JPEG/WebP 근무표 분석
- OCR/비전 모델 기반 시간표 해석
- OpenAI API 기반 이미지 분석
- PDF 근무표 가져오기

이미지 기반 자동화가 필요해질 경우 Excel 가져오기와 분리된 별도 기능으로 다시 설계합니다.
