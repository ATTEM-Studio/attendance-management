# 근무표 자동 가져오기 Implementation Plan

## 현재 범위

근무표 가져오기는 **Excel `.xlsx` 전용**으로 운영합니다. 기존 이미지 분석 구현은 제거하며, Excel 파서와 안전 적용 흐름만 유지합니다.

## 완료 기준

- [x] workbook에서 근무표 후보 영역 자동 탐지
- [x] 여러 시트 중 근무표 가능성이 높은 영역 우선 추천
- [x] 대상 월 및 적용 시작일 처리
- [x] 직원명 자동 매칭 및 별칭 재사용
- [x] 다중 근무 구간 정규화
- [x] 기존 일정과 신규/변경/삭제 diff 생성
- [x] 실제 출퇴근 기록이 있는 일정 보호
- [x] 부분표에서 자동 삭제 금지
- [x] 미리보기 후 적용 직전 서버 재검증
- [x] SHA-256 source fingerprint 검증
- [x] PostgreSQL RPC 원자적 적용
- [x] 적용 후 체크리스트 동기화
- [x] 회귀 테스트 및 PWA build 검증
- [x] 이미지/비전/OpenAI 의존 제거

## 운영 아키텍처

`Excel 파일 → 브라우저 파서 → 직원 매칭 → 서버 미리보기 재검증 → PostgreSQL 원자 적용 → 관리자 화면 새로고침`

Excel 원본은 브라우저에서 읽으며 서버에 업로드하거나 장기 저장하지 않습니다. 서버에는 적용 메타데이터, fingerprint, diff 결과만 기록합니다.

## 제외 사항

이미지·사진·캡처·PDF 분석은 현재 제품 범위에 포함하지 않습니다. 관련 API endpoint, vision adapter, 테스트, UI 선택지는 운영 코드에서 제거합니다.

## 유지해야 할 회귀 조건

- 기존 수동 근무 추가/수정 기능이 그대로 동작해야 합니다.
- 출근/퇴근/추가근무/퇴근 취소 상태 머신을 변경하지 않습니다.
- 이미 실제 근태가 발생한 날짜는 가져오기 기능으로 덮어쓰지 않습니다.
- 미리보기 이후 출근이 발생한 경우 적용 시 보호 상태로 다시 계산해야 합니다.
- 같은 파일이 아닌 경우 기존 preview run으로 적용할 수 없어야 합니다.
